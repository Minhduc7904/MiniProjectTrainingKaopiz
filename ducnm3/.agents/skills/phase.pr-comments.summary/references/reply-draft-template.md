# PR Reply Draft Template

The draft is for manual copy/paste into the PR platform.

Use the same stable comment ids (`C-001`, `C-002`, ...) used in the comment artifacts.

```md
Thanks for the review. I processed the open comments:

- Reviewed: <count>
- Fixed: <count>
- Need discussion: <count>
- Skipped: <count>

Fixed:
- C-001: <short resolution>
- C-002: <short resolution>

Need discussion:
- C-003: <question>

Skipped:
- C-004: <reason>

Verification:
- <command>: <PASS/FAIL>
```

Keep the reply concise. Detailed evidence should stay in `COMMENT-FIX-SUMMARY.md`.
