# Release

## Use when

Preparing a deployable version or changing release procedures.

## Procedure

1. Read the relevant runbook in `docs/runbooks/`.
2. Verify tests, linting, formatting, and required build steps pass.
3. Confirm configuration, secrets, and migrations are prepared without committing sensitive values.
4. Document deployment order, monitoring signals, rollback steps, and ownership.
5. Update the runbook after the release procedure changes or an operational issue is discovered.
