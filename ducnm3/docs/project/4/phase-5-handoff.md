# Handoff từ Phase 4 sang Phase 5

Phase 4 bàn giao spec, Basic Design, testcase và traceability đã duyệt để Dev
triển khai theo từng function ở Phase 5. Backlog triển khai không được quản lý
trong folder Phase 4 nhằm giữ rõ boundary của từng giai đoạn SDLC.

## Điều kiện bàn giao G3

- Spec function đã approved tại G2.
- Basic Design và testcase của function đã approved tại G3.
- Mỗi AC có testcase tương ứng, gồm happy, boundary và negative case.
- Q&A critical đã đóng; thay đổi sau sign-off phải đi qua Change Request.
- Task Phase 5 có Function ID, dependency, estimate và Jira ticket riêng.

Backlog và gate triển khai: [Phase 5 — Development + Self-test](../5/README.md).
