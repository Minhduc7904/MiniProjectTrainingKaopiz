## Setup checklist

Before adding application code, document:

1. Required language runtime and version.
2. Dependency installation command.
3. Environment variables and a safe example file.
4. Commands for running the application, tests, linting, and formatting.
5. Local database or external service dependencies.

Keep this document aligned with the commands defined in project configuration and CI.
