# Agent skills

Mọi skill của project nằm **một chỗ**: `.agents/skills/`.

Đọc skill trong folder đó trước khi sửa code. Không tìm skill ở `skills/`
(folder này đã gỡ). `AGENTS.md` là bảng routing bắt buộc.

```text
.agents/
├── README.md                 ← file này
└── skills/
    ├── README.md             ← danh sách skill và format
    ├── developer-task/       ← WBS/Jira, nhánh ticket, cổng push từ Ngày 3
    ├── frontend-api-page/    ← tạo trang FE một API (mẫu Sổ học viên)
    ├── interface-design/     ← skill UI chính chủ (Dammyjay93)
    ├── api-*-endpoint/
    ├── test-*
    ├── database-migration/
    └── release/
```

Cách dùng:

1. Mở `AGENTS.md` và chọn đúng skill theo loại thay đổi.
2. Đọc toàn bộ file trong folder skill đó.
3. Chỉ bắt đầu code khi đã đọc xong.
