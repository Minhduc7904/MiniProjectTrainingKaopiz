# Liệt kê Quiz của Lesson

API contract: [`GET Liệt kê Quiz của Lesson`](../../api/course-service/endpoints/get-course-lesson-quizzes.md).

Course Service kiểm tra Lesson thuộc Course rồi đọc Quiz của Lesson kèm số câu và tổng điểm (`SUM(points)`) trong một query; HTML mô tả được render từ Markdown khi trả response.
