# Cursor List Courses

## Response standard

JSON success responses use the shared envelope in [`../shared/response-format.md`](../../shared/response-format.md). The concrete JSON below is the value of `data`; add `meta` for `traceId` and pagination. CSV and binary streaming endpoints are exceptions.

`GET /api/courses/cursor?limit=20&cursor=opaque-token`

Success data payload `200 OK`:

```json
{"items":[{"id":"course-uuid","name":"Backend Fundamentals"}],"nextCursor":"opaque-token"}
```

- Validate: `limit` is 1–100; cursor is generated by this endpoint and is opaque.
- Status: `400 INVALID_CURSOR`, `401 UNAUTHENTICATED`.
- Use stable ordering (`created_at`, `id`) to prevent duplicate or skipped rows.
