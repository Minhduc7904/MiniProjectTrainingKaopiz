# Add Endpoint

## Use when

Creating or changing an HTTP or RPC endpoint.

## Procedure

1. Read `rules/code-quality.md`, `rules/testing.md`, and the relevant file in `docs/api/`.
2. Define or update the request, response, authentication, validation, and error contract in `docs/api/`.
3. Implement the endpoint and its business logic with clear separation of responsibilities.
4. Add automated tests for success, validation failure, authorization failure, and expected business errors.
5. Run the relevant quality checks and update API documentation before handoff.
